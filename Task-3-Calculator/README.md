# Basic Calculator – CODSOFT Level 1 Task 3

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Percentage
* Decimal calculations
* Clear function
* Delete function
* Keyboard support
* Responsive design
* Error handling

* CSS3
* JavaScript
