# CODSOFT Web Development Internship

This repository contains the projects I developed as part of the **CODSOFT Web Development Internship**. The projects are based on the Level 1 task list and were created to strengthen my understanding of frontend web development, responsive design, layout creation, and JavaScript fundamentals.

Each task is stored in a separate folder and was developed using beginner-friendly technologies such as **HTML5, CSS3, and JavaScript**.

---

## About the Internship

The CODSOFT Web Development Internship provides practical tasks that help students apply fundamental web development concepts through real projects.

Through these tasks, I practiced:

* Writing clean and semantic HTML
* Designing responsive layouts using CSS
* Using Flexbox and CSS Grid
* Creating mobile-friendly interfaces
* Adding interactivity with JavaScript
* Organizing projects using a clear folder structure
* Managing source code with Git and GitHub

### Task 3 — Basic Calculator

A responsive calculator application that performs common arithmetic operations using JavaScript.

The calculator was created to practice event handling, conditional statements, functions, operators, DOM manipulation, and CSS Grid.

#### Features

* Addition
* Subtraction
* Multiplication
* Division
* Percentage calculation
* Decimal number support
* Clear-all function
* Delete-last-digit function
* Previous-expression display
* Division-by-zero handling
* Keyboard input support
* Responsive button grid
* Mobile-friendly design

#### Keyboard Controls

| Key            | Action            |
| -------------- | ----------------- |
| `0–9`          | Enter numbers     |
| `+`            | Addition          |
| `-`            | Subtraction       |
| `*`            | Multiplication    |
| `/`            | Division          |
| `.`            | Decimal           |
| `Enter` or `=` | Calculate result  |
| `Backspace`    | Delete last digit |
| `Escape`       | Clear calculator  |

#### Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run the Projects Locally

1. Clone this repository:

```bash
git clone https://github.com/Jagadesh7575/CODSOFT.git
```

2. Open the repository folder:

```bash
cd CODSOFT
```

3. Open the required task folder.

For Task 1:

```bash
open Task-1-Portfolio/index.html
```

For Task 2:

```bash
open Task-2-Landing-Page/index.html
```

For Task 3:

```bash
open Task-3-Calculator/index.html
```

Alternatively, open the required `index.html` file directly in any modern web browser.
